# Football Digest Bot
/start -> welcome + instructions. Buttons: Scores, Table, News for 6 competitions.
Telegram Bot API + ESPN public site endpoints (no API key, unofficial). No database.

## Deploy (GitHub + Railway)
1. Push this folder to GitHub.
2. Railway -> New Project -> Deploy from GitHub repo.
3. Variable: BOT_TOKEN (from @BotFather). Optional: TZ_OFFSET_HOURS=1, TZ_LABEL=WAT
